# SKY130 timing library

`sky130_fd_sc_hd__tt_025C_1v80.lib` is the existing SKY130 high-density
typical-corner Liberty file: 25 C, 1.8 V. It uses nanoseconds and picofarads.
The SKY130 standard-cell library is published by
[Google/SkyWater](https://github.com/google/skywater-pdk-libs-sky130_fd_sc_hd)
under Apache 2.0; see `LICENSE.sky130`.

This file was already present before project version control was initialized.
Its exact upstream generation revision is unknown; reproducibility uses the
copy committed in this repository. It does not include physical LEF/GDS views,
other timing corners, or cell simulation models.
